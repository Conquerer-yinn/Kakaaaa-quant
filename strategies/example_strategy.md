# example_strategy 研究笔记

## 策略定位

示例策略，用来跑通"筛选 -> 落表 -> 复盘"的最小闭环，不追求收益本身。

## 当前口径

1. 样本：当日涨停（`limit = U`）。
2. 连板数：`limit_times >= 1`，即首板也纳入。
3. 成交额门槛：`>= 5 亿元`，单位换算沿用全项目口径（`amount` 千元 / 1e5）。
4. 输出列：日期、ts_code、名称、连板数、成交额(亿元)。

## 阶段性结论

- 首板+放量的样本池每天数量可控（多数交易日 10~40 只），适合人工复盘。
- 成交额门槛比换手率门槛稳定，不受流通盘大小影响口径。
