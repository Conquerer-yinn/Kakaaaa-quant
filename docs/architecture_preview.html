总体架构图

这张图表达当前 1.0 的工程结构：左侧是已有自动化 workflow，中心是策略研发 Agent，右侧是 Codex 辅助流。 Agent 内部包含上下文、知识库、tool、编排和 trace，workflow 只提供能力边界与标准化产物。

这版图先作为预览，不直接写入 DEV_SPEC。确认表达准确后，再同步到文档。

总体数据流向图

这张图表达一轮真实策略研发的数据流：用户消息进入 Agent，编排器读取上下文和知识，tool 处理能力边界和草案， 最后导出设计文档；Codex 的结论文档再手动回流到知识库。Trace 贯穿整条链路。

这张图重点看数据、文档、知识和 trace 如何流动，不强调 UI 细节。
flowchart TD
