# 创业板涨停事件研究 V2 设计

## 目标

把第一版“涨停后平均表现”升级为更可信、更可复用的事件研究：在保留原始 1、3、5 日收益的基础上，增加创业板指数基准、超额收益、连板阶段、市场环境、样本过滤和质量报告。

V2 仍然是研究工具，不是交易回测系统。它回答：

> 创业板涨停事件在不同连板阶段和市场环境下，未来 1、3、5 个交易日相对创业板指数表现如何？

## 范围

### 本次包含

- 使用 `399006.SZ` 创业板指数作为基准。
- 计算 1、3、5 日基准收益与个股超额收益。
- 按“首板 / 连板”分组。
- 按事件日全市场涨停数划分“弱 / 中 / 强”环境。
- 排除 ST 股票。
- 排除事件日上市未满 60 个自然日的股票。
- 统计股票基础信息缺失、基准行情缺失等质量问题。
- 新增分组统计和样本质量 Excel sheet。
- API 与前端展示分组统计、质量报告和超额收益。

### 本次不包含

- 分钟级、竞价或盘中触发数据。
- 交易成本、滑点、仓位、买卖执行模拟。
- 自动参数寻优。
- 多因子打分或机器学习。
- 策略研发 Agent。
- 自动定时运行。

## 研究口径

### 基准与超额收益

基准使用创业板指数 `399006.SZ`。

`N 日基准收益 = (基准第 N 日收盘 / 基准事件日收盘 - 1) * 100`

`N 日超额收益 = 个股 N 日收益 - 基准 N 日收益`

基准行情缺失时保留个股原始收益，基准收益与超额收益留空，并在质量报告中计数。

### 连板阶段

- `limit_times <= 1`：首板
- `limit_times >= 2`：连板
- `limit_times` 缺失：未知

### 市场环境

使用事件日 `limit_list_d` 中全市场 `limit == U` 的数量：

- `弱`：不超过 30 家
- `中`：31–60 家
- `强`：超过 60 家

该分组是透明、固定的研究标签，不解释为交易信号。

### 样本过滤

- 股票代码仍需以 `300` 或 `301` 开头。
- 涨停状态仍需为 `U`。
- 名称中包含 `ST` 的股票排除，不区分大小写。
- `事件日期 - 上市日期 < 60` 个自然日的股票排除。
- 股票基础信息缺失时不直接排除，但计入质量报告。
- 事件日或未来 5 个交易日个股行情缺失时不进入完整样本。

## 输出

### 事件明细

保留 V1 字段，并新增：

- `连板阶段`
- `市场环境`
- `事件日基准收盘价`
- `1/3/5日基准收益率(%)`
- `1/3/5日超额收益率(%)`

### 研究摘要

每个观察周期新增：

- 基准平均收益率
- 平均超额收益率
- 超额正收益比例

### 分组统计

对“连板阶段”和“市场环境”分别输出：

- 分组维度
- 分组名称
- 观察周期
- 样本数
- 平均收益率
- 平均超额收益率
- 正收益比例
- 超额正收益比例

### 样本质量

至少输出：

- 候选事件数
- 排除 ST 数
- 排除上市未满 60 天数
- 股票基础信息缺失数
- 未来窗口不足数
- 个股行情缺失数
- 基准行情缺失数
- 完整样本数

### Excel

工作簿固定包含：

1. `研究摘要`
2. `分组统计`
3. `样本质量`
4. `事件明细`
5. `运行信息`

## 架构变化

### 纯计算层

扩展 `build_event_study()` 的可选输入：

- `benchmark_close_by_date`
- `stock_basic_df`
- `market_regime_by_date`

所有新增研究逻辑继续保持无网络、无文件系统依赖。

### 运行层

运行器新增：

- 一次性读取股票基础信息。
- 一次性按区间读取 `399006.SZ` 指数日线。
- 根据每天涨停表构造市场环境标签。

不按股票逐只请求数据，不增加 N 倍网络调用。

### API 与前端

API 响应新增：

- `group_summary`
- `quality_summary`

前端新增“分组统计”和“样本质量”区域，继续使用现有通用表格，不引入新图表库。

## 错误与兼容

- 基准行情完全为空时任务仍可生成原始收益结果，但超额收益为空并显示质量告警。
- 股票基础信息为空时不静默假设样本合格，统一计入“基础信息缺失”。
- 当前没有正式 V1 真实工作簿，因此 V2 工作簿直接采用五 sheet 结构，不增加迁移代码。
- 缺少有效 Tushare Token 时保持现有可读错误。

## 测试

- 个股、基准与超额收益计算。
- 首板 / 连板 / 未知分类。
- 弱 / 中 / 强市场环境边界。
- ST 与上市不足 60 天排除。
- 基础信息和基准缺失计数。
- 分组统计。
- 五 sheet 工作簿。
- 运行器批量指数请求与股票基础信息请求。
- API 新字段。
- 前端指标映射与生产构建。

## 验收标准

- 原 V1 测试继续通过。
- 新增研究测试全部通过。
- Excel 五个 sheet 的列结构稳定。
- API 返回摘要、分组、质量和明细。
- `/strategies` 页面可展示 V2 空状态或真实结果。
- 浏览器控制台无 warning/error。
- 代码审查无 Critical/Important 问题。
