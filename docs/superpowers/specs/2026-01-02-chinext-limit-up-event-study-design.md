# 创业板涨停后 5 日事件研究设计

## 目标

在现有 `Kaka_Quant` 仓库中落地第一条真实策略研究闭环：识别指定区间内的创业板涨停事件，观察事件后第 1、3、5 个交易日的收盘表现，生成可人工复盘的 Excel，并在现有 FastAPI 与 React 页面中展示最新研究结果。

这条闭环的价值不是证明某个策略可以赚钱，而是验证项目能否稳定完成：

`研究问题 -> 历史样本 -> 指标计算 -> Excel 产物 -> API -> 前端复盘`

## 范围

### 本次包含

- 清理远端主线遗留的硬编码 Tushare Token 与飞书 Webhook 默认值。
- 建立 Python `unittest` 测试基线，不新增测试依赖。
- 识别代码以 `300`、`301` 开头且 Tushare `limit_list_d.limit == "U"` 的创业板涨停事件。
- 计算事件后第 1、3、5 个交易日的收盘收益率。
- 计算 5 日观察窗口内的最高收盘收益率和最低收盘收益率。
- 对完整样本生成均值、中位数、正收益比例、最大值和最小值汇总。
- 输出 `研究摘要`、`事件明细`、`运行信息` 三个 Excel sheet。
- 提供最新结果读取接口与同步运行接口。
- 将 `/strategies` 从占位页改成真实研究结果页。
- 更新策略注册表、README 和项目状态文档。

### 本次不包含

- 交易成本、滑点、仓位或买卖执行模拟。
- 盘中触发条件和分钟级数据。
- 自动定时调度。
- 数据库、任务队列或复杂任务状态机。
- 策略研发 Agent、知识库或多 Agent 编排。
- 将事件研究结果描述成已验证的盈利策略。
