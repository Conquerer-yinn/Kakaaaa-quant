# 当前项目状态

## 项目定位

Kaka_Quant 是一个面向 A 股的个人量化研究工作台，当前分为两条主线：

1. `market/`
   用于行情分析、指标观察、盘中盘后辅助判断与消息卡片。
2. `strategies/`
   用于策略研究、历史样本筛选、Excel 复盘，以及后续成熟策略的日常运行。

## 当前重要约定

1. Excel 仍然是当前阶段主输出。
2. `market-sentiment` 默认维护历史主表，而不是单独维护“近期工作簿”。
3. 历史主表命名规则为：`历史数据_起始日期_结束日期.xlsx`。
4. 每次补数先在 `storage/backups/` 生成 `补充数据_起始日期_结束日期.xlsx`。
5. 测试运行统一生成 `测试数据_起始日期_结束日期.xlsx`。
6. 历史页前端只读取最新历史主表，不读取测试工作簿。
7. 历史页默认只展示最近 20 个交易日。
8. 历史页不再单独展示 `daily-basics`。
9. 行情任务统一放在 `market/` 下。
10. 策略脚本与策略研究记录统一放在 `strategies/` 下。
11. FastAPI 当前只做轻量封装层，不做重型任务平台。
12. 飞书卡片不应从 Excel 视图层反向取数。
13. 重要长期知识不能只留在聊天窗口，必须进入 `project_memory/`。
