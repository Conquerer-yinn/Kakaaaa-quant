# 策略体系长期对话原始全文

## 类型

原始全文档案占位文件。

## 说明

这个文件用于保存以后“策略体系长期主窗口”的原始聊天全文或接近全文的重建稿。

适用范围包括：

1. 以往赚钱策略的总结与系统化
2. 策略触发条件、过滤条件、失效场景
3. 策略分类与研究优先级
4. 策略脚本开发前的想法讨论
5. 哪些策略值得继续投入开发

## 使用方式

当你开始在新的长期主窗口中专门讨论策略体系时：

1. 把原始对话按时间顺序追加到这里
2. 尽量保留原问题、原回答、原上下文
3. 形成明确结论后，再同步整理到 `project_memory/decisions/`
