# 原始对话全文档案

这个目录保存的是 **原始聊天全文**，不是摘要，不是决策结论。

目标：

1. 尽可能完整保留某个主对话窗口的重要原文
2. 保证未来即使切换 team、账号、workspace，也能继续回看核心聊天过程
3. 让项目长期知识不只存在于聊天界面里

## 命名建议

- `YYYY-MM-DD_主题_原始全文.md`

例如：

- `2026-03-26_项目总控对话_原始全文.md`
- `2026-03-26_指标体系设计_原始全文.md`
- `2026-03-26_策略系统化讨论_原始全文.md`

## 内容要求

这里尽量保存：

1. 原始聊天过程
2. 原始提问和回答
3. 关键上下文
4. 当时没有进入正式决策、但后续可能还有价值的讨论内容

## 注意

1. 如果只写提炼后的结论，请放到 `project_memory/decisions/`。
2. 这个目录优先保存“全文档案”，不是“整理稿”。
3. 如果暂时做不到完整全文，也请明确标注：
   - 这是全文
   - 还是节选
   - 还是人工整理版

## 建议模板

```md
# 对话主题

## 类型
原始全文 / 节选 / 人工整理版

## 时间

## 来源

## 原始内容

## 备注
```
