# 项目记忆总览

1. `chat_archive/`
   保存重要主对话的原始全文归档或接近全文的重建稿。

   保存结构化结论与关键决策。

## 后续建议

1. 每个长期主窗口都建立一份原始全文档案。
2. 每次形成重要结论后，同步写到 `decisions/`。
3. 每次结构升级后，记得同步更新 `README.md`、`DEVELOPMENT_PLAN.md` 与 `PROJECT_STATUS.md`。
4. 遇到 Excel 模板、图表、外部链接这类“当前先留存、后续再处理”的问题，单独建一份 decision/issue 文件记录现象和排查方向。
