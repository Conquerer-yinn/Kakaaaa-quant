# 项目长期记忆目录

这个目录用于保存 **不应该只依赖聊天窗口** 的项目长期信息。

目标：

1. 保留重要对话的原始内容
2. 保留重要结论的结构化整理
3. 保留当前项目状态与 AI 接手说明
4. 保证项目在切换 team、账号、工作区、模型时，核心知识仍然可迁移

## 目录说明

- `chat_archive/`
  保存重要主对话的原始全文或接近全文的重建稿。
- `decisions/`
  保存结构化决策、规则、摘要。
- `weekly_summary/`
  保存每周或每阶段总结。
- `handoff/`
  保存 AI 接手说明、当前项目状态、统一归档规则。

## 最重要的原则

### 1. 不把聊天窗口当唯一知识库

聊天窗口适合高效讨论，但不应作为项目长期记忆的唯一载体。

### 2. 原始对话和结构化结论分开保存

- 原始全文：放在 `chat_archive/`
- 结构化结论：放在 `decisions/`
- 当前状态和接手说明：放在 `handoff/`

### 3. 项目知识优先沉淀为仓库内 Markdown

这样即使未来：

- 不再使用 Codex
- 改用 Claude 或别的大模型
- 切换账号、team、workspace
- 主对话窗口历史不可访问

项目核心知识仍然可以继续使用。

## 建议使用方式

1. 重要主对话：归档到 `chat_archive/`
2. 形成明确结论：同步写到 `decisions/`
3. 当前项目状态变化：更新 `handoff/PROJECT_STATUS.md`
4. 想让新 AI 快速接手：先看 `handoff/AI_HANDOFF.md`
5. 想统一归档方式：先看 `handoff/ARCHIVE_RULES.md`
