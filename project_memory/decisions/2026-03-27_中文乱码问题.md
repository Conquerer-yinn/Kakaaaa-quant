# 中文乱码问题

## 背景

当前在 Windows + PowerShell + Codex 链路里，中文文件有时会被写成问号或乱码。

## 决策内容

1. 最终文件必须是正常中文，不能把 `\uXXXX` 留在文件内容里。
2. 写代码和文档时，优先用 `apply_patch`。
3. 如果必须通过脚本写文件，必须显式指定 UTF-8。
4. 改完后必须重新读取校验，确认不是问号或乱码。

## 为什么这样定

1. Microsoft 文档说明 Windows PowerShell 5.1 的默认编码并不统一。
2. 默认编码不稳定时，非 ASCII 字符最容易出问题。
3. `\uXXXX` 可以作为脚本内部的临时转义手段，但不应该作为最终文件内容留下。

## 简洁方案

1. 优先用 `apply_patch` 直接改文件。
2. 脚本写文件时：
   - Python 用 `encoding="utf-8"`。
   - PowerShell 用 `Set-Content -Encoding UTF8`。
3. 不把 `\uXXXX` 留在最终文件里。
