# 前后端第一版闭环与文档同步

## 日期

2026-04-02

## 背景

项目在这一轮已经不再处于“是否要补前端和后端”的阶段，而是已经形成第一版真实闭环：

1. FastAPI 已落地。
2. React 前端已落地。
3. `market-sentiment` 历史主表工作流已落地。
4. 三类飞书卡片已经接入后端统一接口。
5. 三类卡片已完成真实 webhook 发送联调。

但项目中的 README、开发计划文档、handoff 文件，仍有一部分停留在更早的阶段口径，需要同步更新。

## 本轮确认的项目事实

1. 前端第一版页面已经固定为：
   - 首页
   - 历史数据页
   - 推送卡片页
   - 策略占位页
2. 历史数据页当前只展示 `market-sentiment`，不再单独展示 `daily-basics`。
3. 历史数据页固定读取最新历史主表里的最近 20 个交易日数据。
4. 历史数据页图表与表格共用同一份真实数据，并通过点击表头切换柱状图指标。
5. `market-sentiment` 已采用后台任务管理，支持启动、轮询和取消。
6. 三类卡片统一由后端 `push_cards.py` 提供预览、刷新和发送能力。
7. 三类卡片都已经完成真实 webhook 发送测试。
8. 当前项目最明确的遗留问题已经收敛到 Excel 模板侧：`externalLinks` 与图表刷新问题。

## 当前阶段共识

1. 前后端第一版已经完成，下一阶段重点是补强和抛光，而不是重做架构。
2. 前端不应该扩成重后台。
3. 后端不应该扩成重型任务平台。
4. 真实历史数据链、真实后台任务链、真实卡片发送链，比页面数量和平台感更重要。
5. 重要状态变化必须同步写入 `project_memory/`，避免窗口之间上下文脱节。

## 下一步建议

1. 优先排查历史主表更新后的 `externalLinks` 与图表刷新问题。
2. 继续完善三类消息卡片的字段设计与稳定性。
3. 继续迁移更多旧项目指标到 `market/`。
4. 开始补 `strategies` 主线的真实研究内容。
