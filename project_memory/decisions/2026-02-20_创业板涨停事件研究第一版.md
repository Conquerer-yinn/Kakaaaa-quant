# 创业板涨停事件研究第一版

## 决策

`strategies/` 主线不再停留在页面占位，先用“创业板涨停后 5 日表现”建立第一条真实研究闭环。

## 研究口径

1. 事件股票代码以 `300` 或 `301` 开头。
2. Tushare `limit_list_d` 的 `limit` 字段必须为 `U`。
3. 事件日收盘价作为收益基准。
4. 观察事件后第 1、3、5 个交易日收盘收益率。
5. 只有未来 5 个交易日完整、且各日行情存在的样本才进入统计。
6. 未来窗口不足和行情缺失分别计数，不静默混入结果。

## 产物

- 纯计算模块：`strategies/chinext_limit_up_event_study.py`
- 运行入口：`strategies/run_chinext_limit_up_event_study.py`
- Excel：`storage/strategy_results/创业板涨停事件研究_起始日期_结束日期.xlsx`
- API：读取最新结果、同步运行研究
- 前端：`/strategies`

## 边界

第一版是事件研究，不包含交易成本、滑点、仓位、买卖执行、分钟数据或盘中触发，不得表述为已验证盈利策略。

## 验证结论

自动化测试覆盖计算、空样本、缺失行情、未来窗口不足、工作簿、运行编排、API 与前端指标映射。

真实 Tushare 冒烟在 2026-02-24 被历史凭据阻塞：自定义网关和官方端点都返回无效 Token。仓库已移除硬编码凭据；拿到新的 `TUSHARE_TOKEN` 后可直接运行，无需修改代码。
