# 创业板涨停事件研究 V2

## 决策

在增加第二条策略研究或策略研发 Agent 之前，先提高第一条事件研究的可信度和可解释性。

## 新增口径

1. 基准固定为创业板指数 `399006.SZ`。
2. 超额收益等于个股同期收益减去基准同期收益。
3. `limit_times <= 1` 标记为首板，`limit_times >= 2` 标记为连板，缺失时标记未知。
4. 事件日全市场涨停数不超过 30 家标记弱，31–60 家标记中，超过 60 家标记强。
5. 名称包含 ST 的样本排除。
6. 事件日上市未满 60 个自然日的样本排除。
7. 股票基础信息缺失时样本保留并计数，避免无证据地判断为合格或不合格。
8. 基准行情缺失时保留个股原始收益，超额收益留空并计数。

## 输出合同

Excel 固定包含：

- `研究摘要`
- `分组统计`
- `样本质量`
- `事件明细`
- `运行信息`

API 固定返回：

- `summary`
- `group_summary`
- `quality_summary`
- `metadata`
- `details`

## 边界

V2 仍然不是完整回测。分组阈值是透明的研究约定，不是自动交易信号；超额收益也不包含交易成本、滑点或可成交性验证。

## 验证限制

代码与模拟数据可以完整验证计算、工作簿、API 和前端合同。真实 Tushare Token 仍未提供，因此真实样本数量、分组分布和结论目前未知，不能用自动化测试结果替代真实数据复核。

## 下一步

1. 使用有效 Token 生成真实 V2 工作簿。
2. 人工抽查事件、排除项、指数日期对齐和超额收益。
3. 确认分组样本量足够后，再判断是否调整阈值。
4. 选择“创业板炸板次日反馈”作为第二条候选事件研究。
