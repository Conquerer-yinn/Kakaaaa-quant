# 市场情绪工作簿协作结论

## 背景

本轮讨论确认，市场情绪工作簿先采用“代码维护数据，用户维护图表模板”的方式推进。

## 决策内容

1. 数据字段先沿用 `测试_近期市场情绪工作簿.xlsx` 的结构。
2. 正式工作簿保留 `总览` sheet，供后续手工放图。
3. 代码只负责更新数据 sheet，不直接生成图表样式。
4. 用户在 Excel 里手工做一次模板，后续更新数据时尽量让图表自动扩展。

## 为什么这样定

1. 先保证数据正确，再优化展示。
2. 用户对图表样式有明确习惯，手工做第一版更高效。
3. 这样可以避免每次新增数据后再手动改图表索引。

## 影响范围

1. `market/jobs/run_market_sentiment.py`
2. `storage/excel_helper.py`
3. 市场情绪相关 Excel 输出文件。

## 后续待确认

1. `最高连板`、`最高连板个股`、`炸板数`、`十日高度是谁` 还要继续核对。
2. 图表自动扩展最终采用 Excel Table 还是命名区域，还要结合实际模板再定。
