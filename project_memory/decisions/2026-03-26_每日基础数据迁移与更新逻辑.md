# 每日基础数据迁移与更新逻辑

## 背景

“每日基础数据”是旧项目中最明确、最适合作为第一条标准任务链的脚本。

## 决策内容

1. 该任务拆成四层：
   - `data_engine/tushare_api.py`
   - `market/indicators/daily_basics.py`
   - `market/jobs/run_daily_basics.py`
   - `storage/excel_helper.py`
2. `run_daily_basics.py` 支持两种模式：
   - 手动区间模式：首次建表或历史补数
   - 增量更新模式：从 Excel 最后一条日期的下一天自动续更
3. “已更新到哪一天”以 Excel 本身为准，不依赖额外状态文档。
4. 写入时按日期去重，保留同一天的最后一条结果。
5. 如果 Excel 文件正被打开，程序应给出明确错误提示。

## 为什么这样定

1. 兼顾首次历史补数与日常更新。
2. 避免重复拉取已存在的数据。
3. 用 Excel 自身作为更新进度准绳，最贴近当前使用方式。

## 影响范围

该任务将作为后续行情任务迁移的参考模板。
